Presentació del projecte

Aquest projecte té com a finalitat posar en pràctica el control de versions d'un projecte web mitjançant Git i GitHub.

Al llarg de la pràctica treballarem amb diferents branques per a desenvolupar funcionalitats, integrar canvis, preparar una versió estable i corregir possibles errors.

Objectius de la pràctica

  • Aprendre a gestionar un projecte amb Git i GitHub.
  • Utilitzar la metodologia Git Flow i les seues branques.
  • Desenvolupar i integrar funcionalitats de manera ordenada.
  • Crear una versió estable i aplicar millores mitjançant un hotfix.
  • Documentar el procés de treball i publicar la documentació amb GitHub Pages.

Com treballem amb Git Flow

Git Flow ens permet organitzar el desenvolupament del projecte mitjançant branques amb funcions diferents.

  • main: conté les versions estables del projecte.
  • develop: integra les funcionalitats en desenvolupament.
  • feature: permet treballar en noves funcionalitats separadament.
  • release: prepara i verifica una versió abans de publicar-la.
  • hotfix: permet corregir o millorar una versió ja publicada.
